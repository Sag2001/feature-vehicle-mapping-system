# 🚗 Feature Vehicle Mapping System

A full-stack web application to manage feature-to-vehicle applicability mapping with pagination and dynamic filtering.

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- Spring Boot
- REST APIs
- MySQL

---

## ✨ Features

- Feature management with category filtering
- Vehicle master data (Platform, Name, Variant)
- Mapping system (Feature ↔ Vehicle ↔ Market)
- Status handling (Applicable / Not Applicable)
- Pagination support in backend API
- Delete mapping functionality
- Clean UI with React state management

## 🔗 API Endpoints

- GET /features
- GET /mappings?page=&size=
- POST /mapping
- DELETE /mapping/{id}

---

## 🚀 How to Run

### Backend

-->Open Spring Boot project in IntelliJ
-->Configure application.properties (MySQL)
-->Run JAR / main class

### Frontend

-->npm install
-->npm start
